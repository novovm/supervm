Each sample is the smallest message+context among that group's valid cases.
pk is renamed public_key; group/parameter metadata is retained explicitly.
message, context, public key and signature bytes are unmodified.

These are compatibility sentinels, not an exhaustive validation suite or a
FIPS/CAVP certificate. Negative sentinel: flip signature byte 0; it must fail.
AOEM's message ABI is raw/internal: the host supplies the FIPS 204 pure-mode
external framing 0x00 || one-byte context length || context || message.
No prehash mode or automatic algorithm negotiation is introduced.
