# ASAS 免费共享服务与用量统计

日期：2026-11-14。状态：用户最新决定；覆盖本轮此前 ASAS 按用量收费、订单预算及 NOV 结算的方向。SDK 0.7 已接 Claude 计量与按 B 配额，尚非真实双机部署验收。

## 本次确认

ASAS 汇集获准使用的 AI 编程服务供多个 B 使用，主要目标是增加服务供给，不只是容灾。用户随后明确：ASAS 不收费，NOV 用于用量统计方向，不再推进 ASAS 收费、扣款或订单结算。

- ACODE 是用户入口；B/C/D 保有本机项目、VS Code、工具执行、审批和操作记录。
- 提供服务的物理 A 运行 NOVOVM 节点及 ASAS 原生 L3 应用；官方 Claude/Codex Agent 在 A 调度，B 执行本地项目操作。外部云模型不因此变成 A 本地推理。
- A 实例、物理宿主、NOVONET 节点、模型账号和额度池分别标识。允许同机多个隔离实例及多物理机，不重复建设网络/账号/加密体系。
- ASAS 不向 B 收费，不预留/扣除 NOV，不向 A 结算 ASAS 服务费，不建立价格表、可花额度、退款或自动付款授权。
- NOV 仍是 NOVOVM 既有原生资产，不另发 ASAS Token，不修改供应、余额、资产权限或原有账本。
- ASAS 只统计实际服务贡献，不因安装、在线、账号数、虚拟机数量或统计值自动发币；NOVOVM 其他业务的既有经济规则不受本次决定影响。

## 统计口径

三类数据分开，不能混成一个余额：

| 数据 | 原始单位与来源 | 不能冒充 |
| --- | --- | --- |
| 网络流量 | 原 NOVONET owner 的实际有效字节；方向、统计层及重传口径明确 | 模型 token 数、NOV 资产或节点已赚收益 |
| 模型用量 | 官方引擎结构化输入/输出/缓存等 token 观察，保留来源、统计范围和响应身份 | 网络字节、订阅剩余额度或已确认费用 |
| NOV 统计展示 | 如需将用量折算为 NOV 参考值，必须另行明确系数、量纲、舍入和版本 | 钱包余额、待付债务、可提现奖励或链上交易 |

目前没有用户确定的字节/token→NOV 换算关系，因此不编造系数、不按币价折算、不显示虚假的 NOV 金额。先保存原始用量；后续参考换算可重算但不能改变资产状态。
如果只展示某节点已有的真实 NOV 数据，须从原账本只读取得并标注其真实含义，不能由 ASAS 计数器生成余额。
默认统计留在受控服务记录，不把聊天正文、源码、凭据或详细使用关系公开上链。

## 去重与归属

统计归属至少区分 A 实例、认证 B 节点、项目、任务、引擎/型号及原始观察身份；同名项目和 Skill 不跨 B 混用。
模型响应重复出现、网络回执重传、恢复后的累计快照均不能直接再加一次。缓存/推理等子项与父项区分，不重复累计；缺失数据标记 unknown，不填0或100%。
网络重传和有效负载分别记录；不得把同一传输在应用层、工具层、NOVONET 层重复当成三份有效贡献。
B 本机编译/测试不能记为 A 提供的计算贡献；统计服务由谁实际提供，不按节点层级分配虚假贡献。
Claude SDK 的 total_cost_usd/costUSD 为本地估算，不用于 NOV 换算、扣款或金融判断。
引擎原始用量来自 A 的可审计观察，不宣称已经无需信任地证明云端 token 真实。

## 免费不改变账号授权

服务是否收费与模型资源能否供其他用户使用分开。账号所有权、额度池独立性和获准使用主体仍需核验。
不集中收集/复制订阅令牌，不以多虚拟机、不同出口或自动轮换个人订阅绕过厂商限制。Claude 当前规则限制第三方以个人订阅代其用户路由请求，不能因免费而视为已获授权。
可接自有且许可对外使用的 SGM、明确获准的商业资源，或官方允许的终端用户自带授权环境。供方自身发生的 API/订阅成本并不因 ASAS 免费而消失，不默认为 B 自动代付或向 B 追收。

## 多 A 与执行安全

多 A 先按用户/项目/数据范围授权、工具和 Skill 版本匹配、健康及真实额度筛选，不只按某账号是否还有额度选择。
quota_pool_id 为不透明限额池标识，不是凭据；同账号/组织限额不按设备重复计算。额度未知或过期就显示未知。
任务仍由一个 A 主控。换 A 前核对 B 已完成、运行中及未知效果，旧 A 撤权后才能交接；未知副作用不重放。execution_epoch 和跨 A 安全交接尚未实现，不能先称无感切换。
新 A 只获取任务允许的上下文和所属 B/项目/Skill 摘要，不复制账号凭据或全局会话。免费不是解除本机审批或跨项目权限。
