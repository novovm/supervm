## 开发目标与本轮调整

用户后续确认改为 NOVOVM 原生插件、并预留同 A 的 Codex/Claude 双引擎。本轮先完成唯一目录、宿主启停、IPC、多引擎协议隔离和同步；下列 B/翻译项不因优先级改变而冒称完成。

1. 文档覆盖架构、协议、安全/过滤/翻译、界面、部署及验收，并明确状态。
2. 加强 A 的落盘顺序、重复结果、取消/工具悬空和重启记录校验，避免基础协议“成功”掩盖未知状态。
3. B 接入轻量出口检查和有保护段的翻译端口，完成真实回环 A/B 文件工具测试。
4. 固定客户端归档摘要；构建/测试通过后更新状态，不在此阶段自动覆盖正在使用的 VS Code 扩展。

## 必须分别记录

构建通过、协议夹具、真实 HTTP/文件 I/O、真实 Claude 推理、跨机 NOVONET、真实 VS Code 宿主、界面截图及长期稳定性是不同证据。
不得把模拟引擎计为 Claude 能力，不把工具注册计为全部本机控制，不把过滤规则计为 SGM 学习。
需要真实凭据、另一设备或网络部署才能验证的项目保持未验收；测试不能复制用户订阅凭据或自动使用付费模型。

## 完整接收条件

- 未认证、越权项目、别的 peer 的 Session/任务/结果均拒绝。
- 同 Session 只有一个活动任务；同任务输入幂等，不同输入冲突。
- 任务和结果落盘后才确认；存储损坏拒绝，活动进程重启进入恢复，不隐式重放。
- B 路径越界、受保护路径、符号链接、过期摘要、脏编辑器和取消后的写入被拒绝。
- 真实源文件、结果及任务指令都走出站检查；秘密不出现在远端、错误或日志。
- 翻译不修改原样段，失败不静默回退；实际中译英质量与时延须另测。
- A 不能通过本地工具改 B 项目或越过 B 批准；GPT/SGM 既有路径不退化。
- 断线、重复投递、取消、客户端/服务端崩溃、事件缺口及有副作用结果未知均有明确状态。

实际记录见 `STATUS.md`，旧失败保留，不把未执行项改成通过。
