# ACODE 原生客户端与界面设计

## 连接与引擎

模型设置提供 Claude 的现有 API/CLI 连接及 ASAS 共享连接配置，实际引擎由连接类型决定。
ASAS 配置 A 地址、设备身份/令牌及项目授权，不要求 B 安装 Claude。凭据不发 webview、不进普通设置或聊天。
菜单分别显示“未配置/传输可达/Claude 未验证/任务运行/需要恢复”；HTTP 健康检查不能直接标记 Claude 模型已就绪。

## 会话皮肤

用户指定参照 Claude Code 的 VS Code 扩展交互。保持 ACODE 自有品牌，不复制闭源扩展代码、官方品牌资产或伪装成官方扩展。
ASAS 路径使用独立样式作用域，调整会话排版、输入框、工具过程和授权卡片；GPT/SGM 保留现有样式。
不靠型号字符串触发皮肤。历史消息保留原引擎、节点、项目和真实工具回执。
切换连接不清空可见历史；后端核心线程与远程 Claude Session ID 分开绑定。跨引擎传递上下文需要数据去向确认，不自动执行旧消息。

## 输入与出站

用户输入和聊天默认中文。发送前可查看英文任务说明以及保持原样的代码/路径段。
过滤失败保留草稿；只显示不含秘密的命中类别和位置。不得把被拦内容放入错误 toast、日志或遥测。
翻译后端未配置时明确显示不可用，不等待加载 SGM，不假装已经翻译。

## 执行和恢复

过程显示 A 的真实 Agent 事件及 B 的工具回执；确认界面明确操作发生在本机哪个项目。
停止分别展示“已请求取消”和真实终态。断线显示原任务 ID，先查状态，不把重连变成重新提交新任务。
不确定副作用显示恢复入口及原调用证据；不使用一键重试默认重放写入。
未接入的 Shell/桌面/目标/多 Agent 控件不显示成可执行能力，不制造空壳开关。

## UI 验收

至少覆盖 280/420/744/1000 像素、亮暗主题、字体继承、键盘与焦点、弹出菜单、长文本、过滤保留草稿、翻译异常、授权/取消、重连和引擎切换。
提供实际浏览器截图及真实 VS Code 安装包宿主检查；文字测试不替代渲染验收。
