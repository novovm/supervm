# 安全与轻量出站处理

状态：安全设计要求。项目绑定、私有 IPC 和基本工具权限已有实现；完整出站扫描、受保护段翻译和最终发送复查尚未接入，不得对外宣称已具备 DLP/翻译保护。

## 信任边界

B 工作区内容、模型文字和远端工具参数都不可信。认证只确定请求归属，不等于允许执行。
A 和 B 分别检查授权；SGM/翻译器的输出不能授予权限。A 的服务配额、B 的工具许可及系统权限取更严格者。
网络令牌不能用作 Claude 凭据；配置、临时文件、会话和执行日志使用私有目录/文件权限。
A 的 Claude 仅开放当前 B 的 MCP 工具，保留官方引擎；B 只开放已注册且授权的宿主接口。

## B 的出站链

1. 只处理将要发送的数据，不扫描用户整台电脑。
2. 扫描自然语言、附件正文、选区、上下文和工具输出，不只扫描输入框。
3. 发现已知私钥块、凭据字段、常见服务令牌或本地已知秘密时阻止导出。错误仅含规则 ID 和位置，不含原文或秘密。
4. 中译英只处理自然语言段；代码、路径、命令、变量名、错误和 JSON 参数作为独立原样段保存摘要。
5. 校验受保护段、生成译文预览，再复查最终发送内容；不允许翻译器改写代码或工具调用。
6. 文本翻译异常、超时或验证失败时不得静默改发原文或换云端服务。

轻量规则是确定性数据检查，不是完整语义理解，不保证识别所有编码秘密、钱包种子或提示词注入。
规则过滤不是绕过执行授权的依据。误报由明确的策略调整处理，不提供全局“跳过安全”开关。

## 翻译接口

本地 `Translator` 端口与过滤分离，不调用 SGM。候选为 OPUS-MT 中译英及成熟 CPU 推理后端，须固定版本、校验模型许可和实际速度/术语质量后才启用。
当前只交付处理合同及可测试接口时，应标记“翻译后端未接入”；测试替身不是模型翻译实测。
中文原文默认留 B；英文说明和受保护原样段发往 A。发送中文原文作为额外上下文需要明确选择，不能随过滤回执泄漏原始秘密。
英文不天然保证更快或更正确。否定词、数量、作用域和开发专名必须参加真实样本验收，程序校验不能证明语义完全等价。

## 工具结果被阻止

如果工具已在 B 执行、正文却不允许出站，返回明确失败回执：“本机已执行，正文被出口策略扣留”。
不声称工具未执行，不返回伪造成功内容，不自动重放。完整结果只保存在 B 的私有调用记录。

## 网络与授权

不关闭 TLS 校验、不跳过权限、不提供远端任意 Shell。当前回环 HTTP 仅限本机开发测试；禁止公网明文。
正式传输复用当前 NOVONET 所有者的合格接口，不能只包一层 NovoRUDP 名称就宣称接通。
云端模型仍会接收经授权发送到 A 后用于推理的内容；节点间加密不等于数据完全不出设备。
个人多设备与多人共享产品的认证条件不同，不承诺一个 Claude 订阅可供所有用户使用。
