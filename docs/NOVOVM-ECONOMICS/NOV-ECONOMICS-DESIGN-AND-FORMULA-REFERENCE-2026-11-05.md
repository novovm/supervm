## 0. 2026-11-05后继确认：转账比例收费与资源服务购买力报价分开

来源：用户在本轮对话完整提供“转账按金额的固定比例收费……记得记录”，要求保存
为后续分析和开发口径。本节覆盖下文S1/S2/S3及旧助手把所有费用统一锚定美元、

### 0.1 三种不同的比例

| 对象 | 当前口径 | 数值状态 |
| --- | --- | --- |
| 用户原生NOV转账费率r | 按计费转账金额收取固定比例，不因NOV升值或设备增加自动反向降低 | 0.1%—0.2%为本次讨论区间，即10—20bps；尚未选定单一值或区间内选择规则，不能静默取中值 |
| 提供者分配比例a | 本类费用中归合格服务提供者的份额，由对应经济规则确定 | 原生交易尚未定值；不能套聊天80/20或恢复旧建议90/10 |
| 单台设备实际份额w | 按本类服务实际合格履约及分配规则取得，不按全网在线设备数自动平分 | 是收入核算变量，不新增共识投票权或按设备发钱规则 |

`F_NOV = A_NOV × r`。r是无量纲有理数，链上沿原整数/最高费/原子核销owner表达，
不使用浮点币值；最小单位舍入、最低额/封顶及失败收费等细节未由本节新增定值。

同样转100 NOV，费用为0.1—0.2 NOV；假设NOV单价P分别为1/100/1000美元，
费用价值分别为0.1—0.2、10—20、100—200美元，始终占本金价值的0.1%—0.2%。
同样转等值100美元，则`A_NOV=100/P`、`F_USD=P×F_NOV=100×r`，币价上涨
并不自动提高同一现实转账价值的手续费。以上为情景算术，不是行情或费率批准。

### 0.2 设备收入、摊薄与币价：不可重复计算增长

在同一核算期、同一类计费服务及一致价格估值假设下：

`设备手续费收入_NOV = V_NOV × r × a × w`；对应现实价值再乘P。

当批次费率/分配不同，应逐笔或逐批求和；不把加权平均当成每笔既定费率。
设备增多而需求不相应增长时，单台任务机会/份额可能下降，不必修改r或a；
其他类别的存储/聊天设备不因在线而平分转账执行费。

只有在同类设备等能力、等机会且需求口径不变的简化假设下，才可用有效设备数N
估算平均收入：币价增10倍、N增2/10/100倍，平均收入价值为原来的5/1/0.1倍；
P增10倍、以NOV计的计费总额增3倍、N增5倍时为6倍。这不是实际任务调度权重。
若现实货币计价总额V_ref不变，`手续费总价值=V_ref×r`，不能再把P的上涨额外
乘一次。真实经济需求、币价、有效服务供给和成本要分别变化、联合测算。

### 0.3 成本和建设采购用来支持经营，不替换用户收费合同

`经营利润 = 实际服务收入 + 合格建设采购收入 - 完全成本`，三项统一期间和货币口径。
地区电价、设备投入/折旧、有效利用率、存储占用及损耗、带宽、维护进入成本模型，
不按某设备自报耗时事后增加用户账单，也不保证任何低效设备都获高回报。
丰厚早期回报是建设/测算目标，不是无条件固定收益；初期设备少也可能订单少。
采购仅购买已批准且可验证的容量/任务，从已发行、实际拨付预算支付；同一义务
不重复计价，不增发、不挪已成立应付。经营收入与过去持币的升值收益分开，后者
不能保证本期电费或投资必能收回。

### 0.4 资源服务报价可调整NOV数量，不反向改转账比例

聊天订阅、寄存、内容分发及计算资源按资源、质量、成本、合理利润及需求形成报价。
NOV购买力变化时可调整后续报价所需NOV；既有已接受报价/已成立义务不追溯改价。
聊天固定5 NOV在假设币价1→1000美元时会变成5→5000美元，不能把这种固定数量
套用为长期可负担套餐。订阅80/20/0仅用于其已定事件，不扩成所有服务比例。
转账本金的比例收费与上述报价是两类合同，不以“所有费用固定美元价值”混写。

用户提出发行参考1美元/NOV及5—10年期望1000美元/NOV，仅作情景目标，不是
市场价格预测、固定兑付、节点回报承诺或本轮启用的价格源。共识不各自实时查行情；
必要报价和价格版本仍沿原owner固定。本节没有选定最终r、a、价格源或执行新收费。

## 5. 公式登记：量纲、前提与适用范围

公式是模型或核对式，除已定供应/守恒规则外，不是定价参数批准。

### F01 供应与生命周期守恒

`S = 100000000 × 10^9 = 10^17`最小单位。
当前权威余额与原费用持有量各计一次；锁定、预算、应付和累计周转不是额外供应。
对同一资金批次、互斥状态：

`最终入资 = 尚未分配 + 活动预留 + 已履约待结算 + 累计已结算 + 累计已退回`。

这是批次生命周期对账，不是把累计支付加回当前账面余额。收入入账/结转/充值也不是
对同一服务收入再分80/20的事件；可退保证金不同时计服务收入与可自由支出国库资金。

### F02 资源执行费与登记支出（候选分项）

`F_exec = F_auth + p_C C + p_R R + p_W W + p_B B + p_Z Z + F_finality`。

| 符号 | 量纲和计量层 |
| --- | --- |
| C、R、W | 规则明确的计算/读取/写入单位；新增持久状态的保存期限另明确，不按设备自报毫秒扣费 |
| B | 已选规范层的字节或GiB及必要传播范围；APFL编码大小、展开大小、实际线上大小不能互换 |
| Z | 该业务实际要求的证明生成/验证单位；批量成本按规则分摊，未证明不收费，不能整批及每笔各收完整证明费 |
| p项、固定F项 | NOV/相应单位及NOV；同一实际工作不得既在固定项又在资源项重复覆盖 |

`F_registration = F_register_exec + F_state_service + D_optional`。
`D_optional`是可选保证金，不是费用收入；退还需满足原状态安全释放、无未决责任等明确规则。
注册状态大小、保存周期、副本和保证金政策未定，不承诺一次费用永久无限保存。

### F03 按金额/增值服务收费（候选选择，不作技术禁令）

本段为原S3模型来源；原生NOV转账当前主收费方向和讨论区间以第0节为准，
不再以这里的“可选附加费”限制用户已明确的比例收费方向。

`F_total = F_base_execution + F_explicit_extra_service`；候选服务价例：
`F_extra = min(r × V, F_cap)`，其中V为合同明确的金额基数，r为无量纲比例。
固定费、比例、分档、最低额/封顶、订阅及组合都可研究，参数与适用事件需批准。
若全体原生交易采用按额附加费，这是新的经济政策，不能伪称CPU/带宽随金额同比增长。
隐私金额收费需对应证明关系，多资产V换算需固定资产单位和合格价格，不能直接相乘币数量。
责任/赔偿服务须有真实义务和资金支持，不因包转发就虚构等额资产风险。

纯比例r、无其他费且每次从本金扣费的假设：`V_k = V_0(1-r)^k`。
若费在本金外支付，不能用此式描述收款本金；纯线性比例不因拆单自动便宜。
`Revenue(r) = r × Volume(r)`：成交量随价格变化，不能固定需求据费率推收益。

### F04 资源用量与聊天/内容成本

`Q_storage = Σ_i bytes_i × qualified_seconds_i`，单位字节·秒，按实际合格副本逐份累计。
`GiB = 2^30 bytes`；`GiB·hour = 2^30 × 3600 byte·seconds`。
若输入已经是所有物理副本量，不再乘副本数。

`C_service = c_B Q_delivery + c_S Q_storage + C_purchased_compute/capacity + C_settlement_allocated`。
c为成本单价；报价用的p不是同一个变量，成本不等于价格。字节计量层、副本、扇出、
普通故障替代和结算费承担在接单前写明；容量费已包含的用量不再单收。

### F05 成本、利润和报价模型

`Profit = I_settled - C_incremental_energy - C_network - C_depreciation - C_storage/maintenance - C_other_agreed`。
各成本口径互斥；租赁总价已包含硬件/电力时不重复加。增量成本和含闲置/维护/备用
分摊的完全成本分别列出，实际订单/利用率不是永远满载。到账NOV不等于已卖出现金。

若C是同币种、同服务范围的提供者完全成本，m为提供者收入中留作收益的目标比例，
`0 <= m < 1`，则 `I_target = C / (1-m)`。
若用户总价中另有已批准网络用途比例s，`0 <= s < 1`，且无未列额外费用，
`F_user = C / ((1-m)(1-s))`。
这不同于成本加成`C(1+m)`；此处收益率按模型成本范围定义，不冒充审计财报毛利率。
订阅s=0.2只适用于相应订阅事件；80%是服务责任预算，不保证当日全部成为提供者收入。
已有服务义务和闲置资金不得为凑模型利润而撤销或挪用。价格还须检验需求和质量，非收益保证。

### F06 货币换算和单位服务预算标定

以下购买力换算适用于相应资源服务报价/分析，不因P上涨自动反向修改第0节的转账r。

`Q_NOV = Q_reference_money / P_reference_money_per_NOV`，只作有版本/期限的报价生成或分析。
各验证者不各读实时汇率/AMM spot；用户已签最高费及已接受报价不追溯扩大。
参考价、协议清算价、市场可成交价、服务报价不是同一个数，不承诺固定兑付。

S1预算模型：`f_NOV = C_budget × k / (N_expected × P_reference_money_per_NOV)`。
C_budget为同统计期的成本预算，N_expected为同期预计有效交易数，k为准备系数；都须
有数据来源，不同时在C里含同一准备金又在k里重复计一次风险。它不是确定性共识收费算法。

### F07 释放、分账和微额的整数处理

候选等分释放额L、共n期、已满足期数k时，可研究累计`A(k)=floor(L × min(k,n)/n)`，
当期`Δ=A(k)-A(k-1)`；在最终一期恰好释放L。L使用最小单位整数，乘法须检查容量。
自然月、cliff、已释放前缀及可用性条件必须明确；不能因重启/恢复再释放一次。
这只是均分候选的整数实现模型，不把所有预算上限都改成无条件自动归属。

费率按版本化整数/有理数表达，先累计精确计量，再按已批准的舍入与余数归属规则结算。
不得逐包向上取整制造收入；各分配输出必须恰好等于实际收款，保证金和应付不重复计钱。
舍入方向、最低结算批次、零钱结转与领取费承担仍待批准，不能因小额不够手续费而清零应付。

## 11. 后继参考：标准转账比例、最低费和封顶

来源S4：[附件逐字归档](references/2026-11-05-nov-transfer-bounded-fee-source.md)。
原文及其商业建议、假设、外链全部保留；归档不等于重新核验银行/Visa、电价、
采购或带宽报价，也不将ChatGPT建议提升为用户批准或数学最优解。

### 11.1 候选参数及精确公式

标准NOV转账候选为20bps（0.2%）、最低0.002 NOV、最高50 NOV；9位小数下
分别为2,000,000和50,000,000,000最小单位。原生提供者90%/网络10%仍是
收益测算候选，不套用已确认的订阅80/20/0。上述数值均未写入激活配置。

`proportional_units = round(amount_units × rate_bps / 10000)`

`fee_units = min(maximum_fee_units, max(minimum_fee_units, proportional_units))`

比例先按明确选定的floor/ceil舍入，再应用上下限；附件推荐ceil，但未因此
批准生产舍入。最低费不是额外加项。必须满足`0 <= minimum <= positive maximum`，
用户签名最高费仍约束最终扣款；低于最低费时拒绝，不抬高用户授权。

在该候选下，转0.1/1/5/10/100/1000/10000/25000/100000/1000000 NOV，
费用分别0.002/0.002/0.01/0.02/0.2/2/20/50/50/50 NOV。极小额仍可能有很高的
有效百分比；聊天等微额服务应沿原订阅/有资金累计结算，不把每个包或重传计成收费转账。
封顶不是任意计算、无限存储或无限收款人数的通行证，不扩展原交易类型或资源上限。

### 11.2 购买力重标定，不在执行热路径查询行情

候选原则：r不因币价自动下降；最低费与封顶可由公开、版本化、共同认可的参数
更新重新标定。更新授权、生效点、可信价格及成本依据尚未交付，当前不自动调价。
发行参考$1/NOV不是可信市场价格，也不是兑付承诺。

### 11.3 成本、经营与有限建设采购的可重算模型

以下均为附件假设，非当前NOVONET测量、现实报价或收益承诺：

| 模型 | 算法与结论 |
| --- | --- |
| PQ数据增量 | `(1952+3309)-(32+64)=5165 B/笔`，不是总成本乘51.7 |
| 100万笔新增材料、20份传播 | `5165×10^6×20/2^30≈96.21 GiB`；假设$0.10/GiB约$9.62 |
