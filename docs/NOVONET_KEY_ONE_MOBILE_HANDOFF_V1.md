KEY ONE 是独立高权限签名角色，支持独立 Android 手机；专用硬件为未来可选增强，不作为 NOVOVM 上线或普通用户资产保护的购买前提。此条覆盖旧文档中仅由官方硬件承担该角色的含义，不降低手机零钱的可信限额。当前不刷机、不恢复出厂、不改设备管理模式，不启用真实收费。

## 唯一职责与复用

- SUPERVM/经济电脑：唯一 UCA 账户/资产/用途合同、可信状态证明、限额、nonce、撤销、原子执行及恢复规则。请接收本编号并登记范围，不复制手机持钥或二维码实现。
- NOVOCHAT电脑：A端请求和响应消费，KEY ONE项目B端软件原型；复用现有Android `AssetKeyOwner`/Keystore和上游AOEM ML-DSA-65单签。KEY ONE Mobile二维码封装归KEY ONE项目，A端消费同一代码，不创建第二种资产签名格式。
- 专用硬件：后续复用同一合同独立验收。硬件工程未提交修改不纳入本轮提交。

## 第一阶段限定

独立测试包：B本机生成密钥，认证后签名，私钥不进入A；A准备请求，B独立解析展示规范字段，A验证签名与原请求完全一致。仅支持现有NOV花费合同，不用花费意图伪装增额、恢复或管理授权。测试对象不代表实际UCA注册。B无可信新鲜状态时不宣称资产授权；原型只允许明确测试域，真实签名/提交入口保持关闭。

二维码为有界传输封装，明确类型、版本、长度、请求关联及完整性；限制分帧数、内存和重组期限，重复帧不重复执行，错误/混帧拒绝。完整性摘要不是认证、时间或账户证明。B不得信任A自报余额/高度/权限；链状态证明和更新可信锚仍待上游合同，不能绕过。A返回签名已验证与链上交易已确认分开显示。

B损坏后的恢复、重新绑定和旧权限撤销继续待定，不承诺仅凭UCA找回资产。普通手机的软件ML-DSA保护不等于安全芯片内签名；系统认证不是交易私钥。禁止私钥/恢复根进入二维码、日志或A端。现有聊天身份历史及v108保留。

## 验收门槛

1. B认证建钥、重启同钥签验；A/B真实相机完整往返，记录分帧识别率及失败。
2. 改金额、收款方、链、费用、代次或有效高度，原响应不能满足新请求。
3. 取消、错误认证、截断、混帧、重复、乱序、超时均有界处理；重复扫码不触发自动签名。
4. 缺失/过旧/无效可信状态不开放资产授权，签名成功不冒充到账。
5. 主链限额、撤销、恢复与真实执行另行验收后才讨论真实收费。
