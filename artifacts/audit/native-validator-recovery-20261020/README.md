## 原入口、复用来源与被替换接线

`novovm-node native_execution_tick → 原 UdpTransport 唯一 socket owner →
AuthenticatedUdpIngressV1 / NativeChannel → NativeLifecycle / RoundProgress →
CandidateBodies / CandidatePipeline → novovm-exec → aoem-bindings → AOEM →
原 ValidatorJournal 的同一状态、决定、归档与链头发布 → 原生类型化查询`。
CPU/整数后端和共识规则未更换，没有另起 controller、执行器、节点模式或权威链头。

| 当前落点 | 已有能力来源 | 这次补齐与替换 |
| --- | --- | --- |
| `consensus/native_lifecycle.rs`、`native_lifecycle/ingress.rs` | 保留的 `consensus/controller.rs` 逐peer调度、退役思路；原对象发送器取消/完成出口 | 替换全目的端同时准入屏障。逐目的端预约；在原32消息/4MiB预算内预留4个耐久控制槽/对应字节。辅助消息不能占满签票出口；实际输入预约再经过同一 `fits`，小预算不足返回背压。 |
| `novorudp/endpoint/reconnect.rs` | 原签名握手、身份/来源绑定、重放缓存、客户端新会话的AEAD确认机制 | 固定验证者显式采用 `enable_configured_reconnect_v1`；失败尝试生成新凭证，不延长旧凭证。新会话须证明新秘密；原身份/日志/资格不变。 |
| `consensus/native_lifecycle/recovery.rs` | 原 `RequestDecision`、`RequestBody`、`ArchiveRead`；旧controller的 `request_archive/poll_archives/request_missing`；当前正文执行和journal | 替换拒绝历史请求分支。按本机精确父上下文请求决定；服务端读本机已验证耐久前缀，先证书后按精确body_id取正文；接收端原鉴权/AOEM独立执行，再经同一journal发布。 |
| 当前 `native_product_*` 进程门禁 | 保留的实际A/A/B、经济核对、归档QC、强杀/恢复方法 | 迁回当前binary/NativeLifecycle，不启动历史Relay controller。CI先枚举实际测试名称，防止空过滤；只上传报告/日志，不上传密钥/数据库。 |

四个控制槽的依据限于现行协议：当前提案、prevote、precommit和紧邻上一高度决定，
不是任意未来消息扩展的通用证明。高度/轮次实际耐久推进后才退役过期实时义务；
已准入对象仍等原handle的终态返回后释放额度，取消不是远端ACK。
决定/正文由本地已验证归档继续提供，不要求离线端先收到全部过时实时票。
每peer最多一个归档读取、一个两消息大小缓存及一个精确正文请求提示；原投递预算不扩大。
缓存有额外显式有限预算，不将“有界”包装为已测出峰值RSS或硬件内存上限。

重连只换传输会话。`SessionReplaced`重投同一份不可变对象，不重新签票或重置日志。
开放客户端与配置验证者不是同一准入政策。默认 `NativeEndpoint::bind` 仍服务原只收数据
适配器；主链的固定peer owner显式启用v1，零固定peer的查询listener不误启用此政策。
这是一份端点实现的版本化生命周期选择，不是两套传输/产品。现用调用者包括
`NativeApflSocket`、原生对象/查询客户端、`product_rendezvous_native`；未完成各调用者
契约迁接前不能删除旧就绪契约。日后统一策略须先迁调用者和相应回归，不可静默改默认。

## 尚未扩大签收的范围

可能更新LOG/OPTIONS；保留的是业务元数据、密钥/配置与原签票outbox，不声称DB文件
字节完全不变。UCA花费授权、PQ、业务ZK和原其他业务能力继续按台账推进。
当前类型化最终回执的依据在 `novovm-protocol/src/native_query.rs`，不是历史JSON展示。

deferred carrier中，直接取消仅调用只改变Sending的 `sender.cancel()`，未设置
排空分支读取的token，可能继续排空；应由共享carrier整改补直接API反例。
当前验证者用非deferred UDP，没有这种部分写，未发现它阻断本轮恢复；本机不扩成
NOVOCHAT/TLS重写，也不把它隐藏在组件全通过里。此项是源码线索，未新跑直接取消反例。

旧controller/channel仍不参与任何feature的活动签票装配；尚未完成映射的历史反例
和复用资产继续保护。已替换的活动全端屏障、验证者会话变化即报错和拒绝归档分支
已经直接移除，不保留旧活动开关。旧参考源码的删除须先完成剩余能力/测试替代表，
