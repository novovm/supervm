## 两处诊断错误及处理

首轮附加组收尾时，复用代码未处理进程退出竞态，TerminateProcess返回拒绝访问，异常遮蔽了该组退出结果。
该组节点实际退出码没有保存，保留为未知，不能补写为0。
已改为收尾前先保存结果，调试器退出后重查进程句柄状态，终止失败后等待并再次核对真实退出状态。
资源采样的退出竞态同样以OS句柄状态核对。完成的BASE保留，恢复阶段只接续附加组和采集组。

恢复后的附加对照正常完成，验证了这次修正的结果落盘路径。
三边界首次命中时，CDB的MASM表达式求值器拒绝了我写入的C++逻辑运算符，出现Numeric expression missing。
该次退出0xE0000001是控制器显式终止，CDB清除断点并detach后退出0，没有原始NOVOVM自然异常证据。

条件表达式已改为MASM的and/or，并显式设置表达式求值器。
已用PID43712既有转储完成三个条件的离线求值检查，CDB退出0。
离线异常上下文中的接收对象使用活动RDI，并在伪寄存器赋值后重新选择.ecxr；该检查仅验证表达式，未制造新的运行记录。
修正后回调及三边界记录完整性仍待运行验收。表达式规则依据微软文档核对。[Microsoft MASM运算符说明](https://learn.microsoft.com/en-us/windows-hardware/drivers/debuggercmds/masm-numbers-and-operators)
