## 控制器误判及离线修正

控制器原解析器假设逻辑断点0/1/2分别对应物理DR0/DR1/DR2。
实际本次三个逻辑断点在依次启停时均使用物理DR0，原始日志分别显示DR0等于各自检查地址，DR7=0x401。
因此原解析器只接受P0，在P1触发断言。CDB本地回调已经继续记录P1和P2，并输出PTR_CHAIN_DONE。
控制器随后清除断点、detach并结束本轮隔离进程，原始结果保留controlled_error及AssertionError。

本轮离线重解只要求当前RVA命中某个实际启用且类型为执行的物理DR槽。
同时核对线程、入口RSP、返回地址、接收对象、事件顺序及源值，不依赖逻辑断点号与物理槽号相等。
原始控制器结果和原始日志没有覆盖。original-controller-result.json仍为1条事件，boundary-events-public.json恢复3条真实事件。
raw_line_sha256与本地日志SHA-256用于复核，原始私有日志未上传。
本次仅离线解析已有记录，没有为补齐表格重跑同一调用。
