### 授权页写集收敛（v4之后，待独立验证）

源码确认：常规grant占一个数据页，但固定512字节记录每次更新都会输出
`Put长度头/Put数据页/Delete本已缺失的尾页`。1024独立授权就产生1024次此Delete，
打断原树planner的连续Put批量构造；16账户同块只需对去重后的16份授权做此工作。
这不是ML-DSA数学开销，也不应靠放松尾页规范性来解决。

候选沿原codec比较同父根已完整校验/解码的旧grant与新grant，只提交实际不同页。
旧记录使用捕获时的原intent编码，避免管理换epoch时错误套用新epoch；None及新开户仍全量，
真正旧尾页缩短继续Delete。原读集、授权、守恒、nonce、费用、原树格式及原执行/journal不变。
该改动不计入上述v4成绩；先用原树最终root/可达节点及构造计数对照，再用独立制品测整链。
