# C 现役查询槽位在线释放核对

北京时间 02:29:36 的 C 现役报告仍显示，唯一的非验证者查询会话绑定 `192.168.71.73:64131`，已约 68 分钟无认证流量。Windows 没有该 UDP 客户端套接字。C 的 `9f223abf` 原 PID 7384 持有 UDP 41052/42052，B 原 PID 571511 在线。[A→C 同窗取证](A-to-C-query-trace-window-20261126.md)

核对实际运行版本。NovoRUDP 有内部 `retire_idle_clients` 接口，用于由持有者安全释放空闲动态会话。在该版本，生产调用点均在 `product_rendezvous_native`，C 的原生共识 `NativeChannel` 没有调用。C 的监听默认关闭空闲退让，已建立的查询会话没有因对端退出或闲置自动回收。原生查询协议没有关闭或管理会话的命令。Windows SCM handler 只处理停止、关机和状态查询，现有生命周期工具也没有释放单个查询客户端的操作。

当前现役没有可用的单会话在线释放入口。按本轮条件保留 C 原进程，A 未发起复测。未补发、未换钥，未修改节点配置或运行状态。
