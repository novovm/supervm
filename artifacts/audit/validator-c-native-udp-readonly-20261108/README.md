## 覆盖边界

PktMon 使用 32MB 循环文件，限定网卡组件。原 counters 显示 Realtek Lower Tx1700、
Upper Tx1670，两处 Rx0；它们是不同组件的观察计数，不能相加作为唯一网络包数。
转换后 pcapng 仅保留上述3包，明显少于组件计数。停止输出虽标记“无事件丢失”，
仍不能据此宣称循环文件保留了全90秒报文或把3包当作完整窗口发包总数。
捕获遗漏或循环覆盖的具体原因尚未独立确定。计数器、ETL、转换输出全部保留。

因此本次不足以宣布“全窗口 A 没有回复”，也不能认定握手认证拒绝、A防火墙或
网络丢包为根因。请 validator-A 用本次精确四元组、时间、transfer 和 digest
关联其原接收/回复记录，再区分未到达、到达未响应或响应未回到C。
不重复发送对象，不强制切换路径，不自动补跑本次采集。
