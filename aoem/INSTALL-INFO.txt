AOEM runtime in SUPERVM is packaged as one portable FULLMAX host bundle.

Runtime baseline:
  AOEM FULLMAX Runtime Baseline 2026-07-31
  AOEM source commit a951273c.
  Windows included and verified.
  Linux included and verified.
  macOS pending, not bundled, not advertised as available.

Primary host model:
  SUPERVM resolves the runtime relative to the repository package:
    aoem/windows/core/bin/aoem_ffi.dll
    aoem/linux/core/bin/libaoem_ffi.so

  The checkout may live on any drive or under any workspace directory name.

FULLMAX continuity:
  The package includes the generic AOEM core plus RocksDB persistence,
  WASM/Wasmtime, zkVM executor, ML-DSA, and KMS/HSM sidecars under:
    aoem/<platform>/core/plugins
    aoem/<platform>/kms-hsm-plugin

Semantic Graph V3 boundary:
  AOEM provides domain-neutral scheduling, atomic persistence, completion, and
  evidence through:
    aoem_submit_semantic_graph_v3
    aoem_bind_semantic_atomic_writer_v1
    aoem_storage_provider_wire_v1

  NOVOVM remains responsible for authentication, nonce and chain-domain
  validation, transaction semantics, balances, and product policy. No
  NOVOVM-specific business logic is built into AOEM.

Source manifests:
  Windows FULLMAX: aoem/windows/manifest.json
  Linux FULLMAX:   aoem/linux/manifest.json
  Host examples:   aoem/host-integration/

macOS:
  pending rebuild; not bundled in this SUPERVM package.
